# Legacy vignettes (temporarily out of build)

Appendix chapters that document **envelope** APIs and **standardized** simulation
entry points (`Envelope*`, `rNormalGLM_std`, `rIndepNormalGammaReg_std`, etc.)
previously shipped from **glmbayes** re-exports. They are kept here while those
symbols are removed from **glmbayes**; use **glmbayesCore** for the same functions.

**Chapter-A01.Rmd** in this folder is an **unrevised snapshot** (pre-split naming).
The built overview is **`../Chapter-A01.Rmd`**.

To knit legacy sources locally, set working directory to this folder or adjust paths to
`../REFERENCES.bib` and load **glmbayesCore** (not unqualified `Envelope*` from glmbayes).
